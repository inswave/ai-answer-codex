`gridView`에서 `mergeCells`를 사용하면 행 또는 컬럼 기준으로 연속된 동일 데이터를 자동 병합할 수 있습니다. 기본적으로 세로 병합은 `mergeCells="bycol"`을 사용하며, 특정 컬럼만 병합하려면 `mergeCol`에 컬럼 ID를 지정합니다.

적용 방법은 다음과 같습니다.

1. `gridView`에 `mergeCells` 속성을 설정합니다.
2. 전체 컬럼이 아니라 일부 컬럼만 병합하려면 `mergeCol="col1,col2"` 형식으로 병합 대상 컬럼을 지정합니다.
3. 좌측 컬럼의 병합 상태를 기준으로 우측 컬럼도 함께 병합해야 하는 경우에는 `mergeCells="byrestriccol"`과 `upperColumn` 설정을 검토합니다.

예시는 다음과 같습니다.

```xml
<w2:gridView id="grd_list" dataList="dataList1" mergeCells="bycol" mergeCol="col1,col3">
    ...
</w2:gridView>
```

스크립트에서 동적으로 적용하는 경우에는 다음과 같이 호출할 수 있습니다.

```javascript
grd_list.mergeCells("bycol");
```

주요 옵션은 다음과 같습니다.

- `bycol`: 같은 컬럼에서 연속적으로 같은 데이터가 있는 행을 세로 병합
- `byrow`: 같은 행에서 연속적으로 같은 데이터가 있는 컬럼을 가로 병합
- `byrestriccol`: 왼쪽 컬럼의 병합 상태를 기준으로 현재 컬럼을 병합
- `never`: 병합 해제

주의할 점은 `mergeCells`는 연속된 동일 데이터를 기준으로 동작하므로, 정렬이나 필터 적용 후 데이터 순서가 바뀌면 병합 결과도 달라질 수 있습니다. 실제 화면에서 병합이 되지 않거나 의도와 다르게 표시되는 경우에는 사용 중인 WebSquare 엔진 버전, `gridView` XML, 병합 대상 컬럼 구조, 샘플 데이터를 함께 확인해야 합니다.

selectBox 항목은 `dataList` 기준으로 동적으로 바인딩할 수 있습니다. 일반 `selectBox`는 `setNodeSet()`, `gridView`의 `inputType: select` 컬럼은 `setColumnNodeSet()`을 사용해 항목 목록을 변경합니다.

적용 방법은 다음과 같습니다.

1. 선택 항목으로 사용할 `dataList`를 준비합니다.
2. 화면 표시값으로 사용할 컬럼 ID와 실제 값으로 사용할 컬럼 ID를 정합니다.
3. 일반 `selectBox`는 `selectbox1.setNodeSet("data:dataList1", "lbl", "code")` 형식으로 호출합니다.
4. `gridView` select 컬럼은 `gridView1.setColumnNodeSet(colIndex, "data:dataList1", "lbl", "code")` 형식으로 호출합니다.

예시입니다.

```javascript
// 일반 selectBox의 항목을 dataList 기준으로 변경
selectbox1.setNodeSet("data:dataList1", "lbl", "code");

// gridView inputType: select 컬럼의 항목을 dataList 기준으로 변경
gridView1.setColumnNodeSet("itemCol", "data:dataList1", "lbl", "code");
```

주의하실 점은 `gridView.setColumnNodeSet()`은 `select`, `autoComplete`, `checkcombobox` inputType 컬럼의 itemset을 컬럼 단위로 변경하는 API입니다. 현재 참고자료 기준으로는 grid의 row별로 서로 다른 `dataList`를 직접 바인딩하는 API는 확인되지 않으므로, row별 항목 구성이 필요하면 조건에 맞는 `dataList`를 별도로 구성해 컬럼 바인딩을 변경하거나 table 구조에서 개별 `selectBox`를 사용하는 방식을 검토해 주세요.

정확한 안내를 위해 사용 중인 WebSquare 엔진 버전, 대상 컴포넌트가 일반 `selectBox`인지 `gridView inputType: select`인지, 그리고 row별 필터링이 필요한지 컬럼 전체 항목 변경인지 확인 부탁드립니다.

`$p.dynamicCreate(id, componentName, options, parent)`를 사용하면 런타임에 WebSquare 컴포넌트를 동적으로 생성할 수 있습니다. `options`는 Object 형태로 전달해야 하며, `parent`를 지정하지 않으면 HTML `body`에 추가됩니다.

적용 절차는 다음과 같습니다.

1. 동적으로 추가할 부모 컴포넌트를 준비합니다.
2. 생성할 컴포넌트의 고유 `id`를 정합니다.
3. `componentName`에는 생성할 컴포넌트명을 지정합니다. 예: `group`, `input`, `trigger`, `selectbox`
4. `options`에는 `style`, `className`, `placeholder` 등 생성 옵션을 Object로 전달합니다.
5. `parent`에는 컴포넌트를 추가할 대상 컴포넌트 객체를 지정합니다.

예시는 다음과 같습니다.

```javascript
var cmpResult = $p.dynamicCreate(
    "ibx_dynamic",
    "input",
    {
        style: "width:200px; height:24px;",
        placeholder: "Please enter your name.",
        className: "cm_form"
    },
    grp_target
);

cmpResult.setValue("WebSquare");
```

Trigger 컴포넌트를 생성하는 예시는 다음과 같습니다.

```javascript
var cmpResult = $p.dynamicCreate(
    "btn_dynamic",
    "trigger",
    {
        style: "min-width:80px; height:24px;",
        className: "cm_form"
    },
    grp_target
);

cmpResult.setValue("조회");
cmpResult.bind("onclick", scwin.btn_dynamic_onclick);
```

주의사항은 다음과 같습니다.

- 생성할 `id`는 화면 내에서 중복되지 않도록 관리해야 합니다.
- `options`를 XML 문자열 형태로 전달하는 방식은 정상 동작 여부를 별도 확인해야 하며, 기본 사용 방식은 Object 전달입니다.

가능합니다. WFrame 자식 화면에서 부모 화면으로 접근할 때는 부모 화면의 `wframe`에 `scopeInherit`를 설정하고, 자식 화면에서 `$p.main()`을 사용해 부모 scope의 `scwin` 또는 컴포넌트에 접근할 수 있습니다.

적용 방법은 다음과 같습니다.

1. 부모 화면의 `wframe`에 `scopeInherit="api"` 또는 `scopeInherit="all"`을 설정합니다.
2. 자식 화면에서 부모 화면의 사용자 정의 함수는 `$p.main().scwin.함수명()` 형태로 호출합니다.
3. 부모 화면의 컴포넌트나 DataCollection은 `$p.main().컴포넌트ID` 형태로 접근합니다.
4. 반대로 부모 화면에서 자식 WFrame 내부 객체에 접근할 때는 `wframeId.getWindow()`를 사용합니다.

예시는 다음과 같습니다.

```xml
<w2:wframe id="wfm_child" src="[첨부파일]" scopeInherit="api"></w2:wframe>
```

```javascript
// 자식 화면: 부모 화면에 정의된 사용자 함수 호출
$p.main().scwin.fnParentCallback("전달할 값");

// 자식 화면: 부모 화면의 컴포넌트 접근
$p.main().ibx_parent.setValue("전달할 값");
```

```javascript
// 부모 화면: 자식 WFrame 내부 객체 접근
wfm_child.getWindow().ibx_child.setValue("WebSquare5");
```

`scopeInherit`는 목적에 따라 선택해 주세요.

- `api`: 자식 화면에서 `$p.main()`으로 부모 scope에 접근합니다.
- `component`: 자식 화면에서 부모 컴포넌트를 직접 참조할 수 있습니다.
- `all`: `api`와 `component` 기능을 모두 사용합니다.
- `recursive`: 중첩된 WFrame 구조에서 상위 WFrame의 scope까지 참조가 필요할 때 사용합니다.

동일한 ID의 컴포넌트가 부모와 자식 화면에 모두 있는 경우 참조 우선순위에 영향을 받을 수 있으므로, 부모 객체 접근은 `$p.main().컴포넌트ID`처럼 명시적으로 작성하는 것을 권장합니다.

3. 행 전체를 변경할 경우 `setRowBackgroundColor`를 호출합니다.

```javascript
for (var i = 0; i < dcList.getRowCount(); i++) {

    }
}
```
