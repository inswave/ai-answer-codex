1. 시스템 개요

  • 인스웨이브 기술지원팀이 고객 기술문의에 대해 유사 사례 검색(RAG)과 답변 초안 자동 생성을 수행하는 시스템입니다
  • 9개 데이터 소스에서 수집한 약 3만 건의 통합 Q&A를 분류·인덱싱하여 답변 근거로 활용합니다
  • 실시간 답변 처리(런타임) · 주간 데이터 갱신(배치) · 운영 감시 3개 축으로 구성됩니다

2. 시스템 구성도

외부 채널에서 인입된 문의가 인터페이스 → 답변 처리 파이프라인 → 검색·생성 엔진 → 데이터 계층을 거쳐 처리되며, 별도의 배치·감시 프로세스가 데이터 갱신과 서비스 가용성을 담당합니다.

3. 요청 처리 시퀀스 (런타임 상세)

src/generator/pipeline.js의 process()가 문의 1건을 다음 순서로 처리합니다. 각 단계는 분기·예외에 따라 생략되거나 조기 종료됩니다.

단계처리 내용분기 · 예외 처리
①입력 마스킹 · 캐시 조회동일 질문 캐시 hit 시 검색·생성을 생략하고 즉시 반환합니다 (첨부 포함 질문은 캐시 제외)
②서비스 요청 차단 판정라이선스·데모·파일 제공·계약 등은 RAG·LLM을 거치지 않고 담당자 안내 템플릿만 반환합니다(BLOCKED)
③RAG 하이브리드 검색유사 사례 상위 8건 검색. 신뢰도가 임계값 미만이면 쿼리를 보강해 재검색합니다(최대 2회)
④MCP 컨텍스트 보강WebSquare 컴포넌트 스펙을 주입합니다. MCP 비활성·실패 시 생략하고 진행합니다
⑤첨부 처리첨부 이미지 OCR(Tesseract) + 첨부 컨텍스트를 추출합니다. 첨부 없으면 생략합니다
⑥답변 정책 판정질문·첨부 기준 위험도 산정 → blocked/human_review 시 사람 검수 안내로 전환합니다
⑦답변 초안 생성Codex CLI(codex exec)를 호출합니다. 한국어 비율 미달 등 품질 미흡 시 재시도합니다
⑧API 존재 검증응답의 API·이벤트·속성을 로컬 가이드·RAG DB에서 확인합니다. 미확인 시 해당 API 제외 후 최대 1회 재생성합니다
⑨마스킹 · 저장 · 등록개인정보 마스킹 → 답변 파일 저장 → 검수 큐 등록 → 답변 캐시 저장

※ 후속 문의(follow-up)는 processFollowUp()이 원문·이전 답변을 함께 입력으로 동일 흐름을 수행합니다.

7. RAG 하이브리드 검색

벡터 검색과 키워드 검색을 가중 결합하여 의미·표현 양쪽을 모두 반영합니다.

처리 순서

  • 쿼리 전처리 — 검색 품질 향상을 위한 정규화·보정(preprocessor)
  • 벡터 검색 — e5 쿼리 임베딩 후 코사인 유사도 계산 (후보 = 반환 수의 3배)
  • BM25 키워드 검색 — BM25Okapi 기반(최초 1회 인덱스 빌드)
  • 점수 결합 — 정규화 후 가중 합산 (벡터 0.6 : BM25 0.4)
  • 상위 8건 선정 — 건당 최대 2,000자로 컨텍스트 구성

주요 사양

8. 핵심 설계 포인트

  • 상주 RAG 검색 서버 — 매 요청마다 임베딩 모델을 새로 로딩하던 약 18초의 비용을 제거하기 위해, 모델·인덱스를 프로세스에 상주시킵니다
    • 표준 라이브러리 HTTP 서버(포트 8765), 127.0.0.1 로컬 바인딩으로 외부에 노출되지 않습니다
    • 서버 장애 시 Node가 searcher.py 서브프로세스 방식으로 자동 폴백하여 무중단에 가깝게 동작합니다
  • 답변 캐시 — 동일 질문 재요청 시 검색·생성을 생략하고 즉시 반환합니다 (추가 비용 없음)
    • 디스크 JSON 1개로 보관하여 프로세스 재시작 후에도 유지됩니다. TTL 30일, 최대 500건
    • OCR 결과가 가변적인 첨부 포함 질문은 캐시에서 제외합니다
  • 인덱스 동기화 — 상주 서버는 기동 시점의 인덱스를 메모리에 보유하므로, 주간 재인덱싱 후 서버 재시작이 필수입니다 (재시작 공백은 서브프로세스 폴백으로 보완)
  • API 존재 검증 루프 — 존재하지 않는 API를 답변에 포함하는 환각을 방지합니다. 미확인 항목 발견 시 해당 API를 제외하고 최대 1회 재생성합니다
  • 개인정보 마스킹 — 입력·출력 양단에서 이름·이메일·회사명·프로젝트명을 제거하여 민감정보 노출을 차단합니다
