[공지] 기술지원 게시판 리뉴얼 — AI 자동 답변 서비스 오픈

안녕하세요. 인스웨이브 기술지원팀입니다.

평소 기술지원 게시판을 이용해 주시는 고객 여러분께 감사드립니다. 더 빠르고 근거 있는 답변을 위해 게시판을 AI 자동 답변 서비스와 함께 새롭게 리뉴얼하였습니다. 주요 내용을 안내드립니다.

[필독] 본 기술지원 서비스(AI 자동 답변 포함)는 유지보수 계약 업체에 한하여 제공됩니다. AI 답변이 제공되지 않거나 충분하지 않은 경우, 엔지니어 답변을 요청하시면 기존과 동일하게 담당 엔지니어가 답변드립니다.

리뉴얼 배경

그동안 기술지원 게시판은 문의 접수 후 담당 엔지니어가 사례를 확인하고 답변을 작성하는 방식이라, 문의 시점에 따라 답변까지 시간이 걸리는 경우가 있었습니다. 이번 리뉴얼에서는 그동안 축적된 방대한 기술지원 데이터(기술문의·개발가이드·공식 문서 등)를 검색·분석하여, 문의 등록 후 수 분 내에 AI가 답변 초안을 자동으로 제공합니다. 담당 엔지니어의 검토 답변도 기존과 동일하게 제공됩니다.

새로워진 주요 기능

  • AI 자동 답변 초안 — 문의를 등록하면 유사한 과거 사례와 공식 가이드를 바탕으로, AI가 '원인 분석 → 해결 방법 → 확인 사항' 순으로 답변 초안을 즉시 작성해 드립니다. 담당자 답변을 기다리지 않고 우선 확인하실 수 있습니다.
  • 답변 근거(참고자료) 제공 — 답변이 어떤 사례·문서를 바탕으로 작성됐는지 출처를 함께 표시하여, 근거를 직접 확인하고 신뢰도 높게 활용하실 수 있습니다.
  • 첨부 소스(.xml 등) 분석 — 문의에 화면 XML이나 스크립트를 첨부하시면, AI가 해당 소스를 직접 읽어 고객님의 화면 구조에 맞춘 구체적인 답변을 제공합니다.
  • 개발가이드 샘플 다운로드 — 관련 WebSquare 공식 예제가 있는 경우, 검증된 샘플 파일을 답변과 함께 바로 내려받아 적용하실 수 있습니다.
  • 이어서 질문하기 — 답변 확인 후 궁금한 점이 남으면, 같은 문의에 이어서 질문하여 맥락을 유지한 후속 답변을 받으실 수 있습니다.

이용 방법

  1. 게시판에서 [문의하기]를 선택합니다.
  2. 제품 / 회사(프로젝트)명 / WebSquare 버전을 입력합니다.
  3. 문의 내용을 작성합니다. (현상과 재현 절차를 구체적으로 적고, 관련 소스를 첨부하시면 좋습니다.)
  4. 등록하면 수 분 내에 AI 답변 초안이 표시됩니다. 추가 문의는 이어서 작성하실 수 있습니다.

더 나은 답변을 위한 작성 팁

AI는 문의에 담긴 정보를 바탕으로 답변하므로, 아래 정보를 함께 적어 주시면 답변 품질이 크게 향상됩니다.

  • WebSquare 엔진 버전 — 미리보기 화면에서 Ctrl+우클릭 → 디버그 메뉴 → "Version 정보"에서 확인
  • 재현 절차 — 어떤 동작에서 어떤 현상이 발생하는지 순서대로
  • 에러 메시지 / 로그 원문과 관련 소스 파일(화면 XML·스크립트)

유의 사항

  • 본 서비스는 유지보수 계약 업체에 한하여 제공됩니다.
  • AI 답변은 초안이며, 사안에 따라 담당 엔지니어가 검토 후 추가 답변을 드립니다.
  • WebSquare 버전·환경에 따라 동작이 다를 수 있어, 적용 전 사용 중인 환경에서 확인을 권장합니다.
  • AI 답변에 포함된 예제 코드 중 일부는 유사 사례 기반 참고용일 수 있으니, 실제 동작 확인 후 적용해 주세요.

문의 및 의견
